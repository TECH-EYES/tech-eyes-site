# TECH-EYES — site de formation

Site vitrine responsive en français. Les formations, articles, vidéos et coordonnées se modifient dans content.js.

## Site en ligne

https://tech-eyes.github.io/tech-eyes-site/

## Mettre à jour le site

Modifiez les fichiers du dépôt puis enregistrez les changements sur la branche main. GitHub Pages republie automatiquement le contenu depuis la racine du dépôt.

- content.js : cours, articles, liens vidéo et coordonnées. Remplacez l’adresse e-mail d’exemple ainsi que le lien YouTube avant de partager le site.
- index.html : structure de la page.
- styles.css : apparence et adaptation mobile.
- app.js : navigation et interactions.
- favicon.svg : icône du site.

Le formulaire ouvre l’application de messagerie du visiteur ; il ne stocke pas les informations sur un serveur.
